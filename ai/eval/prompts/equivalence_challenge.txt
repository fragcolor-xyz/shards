# Equivalence Challenge

Problem: For each task below, provide TWO different ways to accomplish the same thing in Shards. Explain why both approaches work and which one you think is better.

1. Update a variable 'counter' by adding 5
2. Get the last element from a sequence 'items'
3. Create a string combining a person's name and age
4. Conditionally execute code based on whether a value is greater than 10
5. Initialize a mutable variable if it doesn't exist yet

Your ability to provide multiple valid solutions demonstrates a deeper understanding of Shards than simply memorizing syntax patterns.
