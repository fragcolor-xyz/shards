# Immutable vs Mutable Variables

Problem: Write a Shards script that demonstrates the difference between immutable and mutable variables.

Your script should:
1. Create an immutable variable 'count' with value 10
2. Create a mutable variable 'total' with value 5
3. Try to update both variables by adding 3 to each
4. Log the results

Explain in comments what happens with each variable and why.
