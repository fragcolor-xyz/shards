# Table Manipulation

Problem: Write a Shards script that works with tables. Your script should:

1. Create a mutable table 'person' with fields 'name' ("Alice"), 'age' (30), and 'city' ("New York")
2. Update the name to "Bob"
3. Increase the age by 5
4. Add a new field 'occupation' with value "Engineer"
5. Remove the 'city' field
6. Log the final table

Use both colon syntax and Take/Update operations in your solution.
