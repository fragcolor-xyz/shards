# Control Flow Challenge

Problem: Create a Shards script that implements a "fizzbuzz" solution for the numbers 1 to 15. Your script should:

1. Loop through numbers 1 to 15
2. For each number:
   - If divisible by both 3 and 5, log "FizzBuzz"
   - If divisible by only 3, log "Fizz"
   - If divisible by only 5, log "Buzz"
   - Otherwise, log the number itself

Use appropriate control flow structures in Shards to implement this.
