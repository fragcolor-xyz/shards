# Wire State and Communication

Problem: Create a Shards program with multiple wires that demonstrates wire state and communication. Your program should:

1. Define a parent wire that initializes a counter to 0
2. Define a child wire that increments the counter by 1
3. Execute the child wire directly (Do) and log the counter
4. Define another wire that increments the counter by 5
5. Execute this wire with Detach and log the counter
6. Create a global variable and show how both wires can access it

Explain the difference between Do and Detach, and why the counter behaves differently in each case.
